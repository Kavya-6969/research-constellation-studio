# Research Constellation Studio

*"Build a clean, modern, dark-themed web application for ResearchGraph (Problem Statement 03). The UI should look like a professional, high-end developer workspace (similar to a sleek combination of Linear and Miro) with zero clutter.
Please generate the following layout and core components:


Main Infinite Canvas (React Flow / Custom Canvas): A smooth, pannable and zoomable workspace where research artifacts (Papers, Datasets, Notes, and Agent Thoughts) appear as clean, beautifully styled draggable cards connected by smooth edges.

Collapsible Left Sidebar: A clean navigation panel for managing research workspaces, searching nodes globally, and filtering artifacts by tags (e.g., #AI, #Transformer, #Datasets).

Action Header: A top toolbar with buttons for 'Upload Source', 'Cluster Canvas', and a status indicator for the AI Agent Team.

Right Agent Activity Sidebar: A sleek live feed showing the AI Agent Controller's thoughts, current tasks, and interactive Approve / Reject buttons for human-in-the-loop control.

Use Tailwind CSS with a polished dark color palette (slate/zinc dark backgrounds, subtle neon/indigo accents for active nodes, clean typography). Make sure all components fit cleanly on screen without overflow issues."*
